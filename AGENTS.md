# AgentBlazor — Agent Instructions

## Project Overview

AgentBlazor is an **agentic component library for ASP.NET Core Blazor** that adds AI agent chat surfaces, deterministic app actions, and approval-gated workflow execution to Blazor apps. Built on:

- **Microsoft Agent Framework** (`Microsoft.Agents.AI.*` packages)
- **MudBlazor** component library
- **AG-UI protocol** for agent-UI interaction
- **Target**: Blazor .NET 10 web apps (multi-targets net8.0/net9.0/net10.0 for library projects)

**Version**: `0.2.24-internal.1` (private build)
**Fork**: `arisng/AgentBlazor` from upstream `ashpeterson/AgentBlazor` using mirror/merge model

## Build & Test

```bash
# Build full solution
dotnet build

# Build demo only
dotnet build demo/AgentBlazor.Demo/AgentBlazor.Demo.csproj

# Run all tests
dotnet test AgentBlazor.slnx --configuration Debug
```

**SDK**: .NET 10.0.106 (with `latestMinor` rollforward)

## Conventions

1. **Multi-targeting**: Library projects target `net8.0;net9.0;net10.0`; tests and demo target `net10.0`
2. **Central package management**: `Directory.Packages.props` with `ManagePackageVersionsCentrally`
3. **Nullable enabled** everywhere
4. **Implicit usings** enabled
5. **Namespace conventions**: `AgentBlazor.*` root namespace, sub-namespaces mirror folder structure
6. **Internal visibility**: Tests use `InternalsVisibleTo` for internals
7. **CSS isolation**: Component CSS files with `.razor.css` pattern
8. **Static assets**: `wwwroot/` with `_content/AgentBlazor/` for package assets

## Architecture Patterns

1. **Attribute-driven capability discovery**: `[AgentAction]`, `[AgentReadable]`, `[AgentParam]`, `[AgentComponent]`
2. **Builder pattern**: `AgentBlazorBuilder` → `AgentRegistrationBuilder` for configuring agents, workflows, capabilities, tools
3. **Middleware pipeline**: `IAgentTurnMiddleware` with `AgentTurnContext` for cross-cutting concerns
4. **Conversation store abstraction**: `IConversationStore` with in-memory, JSON file, and (paid) SQLite implementations
5. **Provider seam**: `ConfigureChatOptions(Action<ChatOptions>)` for provider-level option pinning

## Fork Model

This is a **fork** (`arisng/AgentBlazor`) from upstream (`ashpeterson/AgentBlazor`) using mirror/merge model:

- **`master`** — clean mirror of `upstream/master`. Never receives local commits.
- **`develop`** — all divergence lives here. Merge the refreshed mirror in periodically.

**Key divergence points**:
- `ConfigureChatOptions` provider hook for gpt-5.6 reasoning_effort fix
- Markdown rendering enhancement (Markdig sanitized pipeline)
- Private-feed publishing scripts
- Version suffix (`0.2.24-internal.1`)

See [`DIVERGENCE.md`](DIVERGENCE.md) for full divergence tracking.
