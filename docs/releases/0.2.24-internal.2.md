# AgentBlazor 0.2.24-internal.2

> **Private/internal bugfix build.** This version is published only to the private local feed (`AGENTBLAZOR_LOCAL_FEED`, default `%USERPROFILE%\.agentblazor-feed`) and is **not** intended for public consumption.

## Bug fix

- **Streaming markdown line-break corruption** — `ChatClientRuntimeAdapter.RunTurnStreamingAsync` silently dropped text deltas where `string.IsNullOrWhiteSpace(delta)` was `true`. A bare newline (`"\n"`) delivered as its own streaming delta was dropped, causing adjacent markdown lines to join (e.g. `"## Executive Summary\nThe in-platform..."` became `"## Executive SummaryThe in-platform..."`). Fixed by changing the guard to `string.IsNullOrEmpty(delta)` so whitespace-only deltas (notably newline-only) are accumulated into `ResponseText` and streamed as `TextMessageContent`.

## Regression test

- `ChatClientRuntimeAdapter_PreservesNewlineOnlyStreamingDeltas` — drives the real streaming path with a scripted `IChatClient` yielding a `"\n"`-only delta between a heading and paragraph. Asserts both the `TextMessageContent` event contains the newline and the assembled `ResponseText` preserves it.

## Verification

- `tests/AgentBlazor.Core.Tests` — 288 passed / 0 failed (includes the new regression test).
- `tests/AgentBlazor.Components.Tests` — 157 passed / 0 failed / 1 skipped.
- `tests/AgentBlazor.IntegrationTests` — 169 passed / 0 failed.
- Empirical red-green proof: reverting the fix to `IsNullOrWhiteSpace` causes the regression test to fail; restoring `IsNullOrEmpty` makes it pass.

## Upgrade notes
