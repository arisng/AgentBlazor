# AgentBlazor 0.2.26-internal.1

> **Private/internal fork build.** This version is published only to the private local feed (`AGENTBLAZOR_LOCAL_FEED`, default `%USERPROFILE%\.agentblazor-feed`) and is **not** intended for public consumption.

## New: `GetSessionSummariesAsync` API — bulk session metadata without N+1

`IConversationStore` now exposes `GetSessionSummariesAsync(int? maxCount, CancellationToken)` which returns `IReadOnlyList<SessionSummary>` — lightweight per-session metadata (title, last message, turn count, last activity) in **one call**, eliminating the N+1 `GetHistoryAsync()` loop that the session browser previously required.

### New types

- **`SessionSummary`** — a `sealed record` in `AgentBlazor.Core.Runtime.Conversation`:
  - `SessionKey`, `Title`, `LastMessage`, `Turns`, `LastActivity`
  - Computed helpers: `BaseSessionId`, `AgentName` (parse from `"id::agent::name"` key)
  - `GetDisplayTitle(IReadOnlyList<ConversationTurn>? turns)` — falls back to first user message when `Title` is null
  - `TruncatePreview(string?, int maxLength = 140)` — shared static preview-truncation helper

### Changes to `IConversationStore`

- **New method**: `Task<IReadOnlyList<SessionSummary>> GetSessionSummariesAsync(int? maxCount = null, CancellationToken ct = default)`
- **Default interface method**: falls back to `GetActiveSessionsAsync()` + batched `GetHistoryAsync()` with early exit and `maxCount × 3` bound — zero breaking changes for existing custom stores.
- **`TruncatePreview` on the interface**: now delegates to `SessionSummary.TruncatePreview` (shared implementation).

### Store overrides

| Store | Implementation |
|-------|---------------|
| `InMemoryConversationStore` | In-memory projection from `_sessions` dictionary |
| `JsonFileConversationStore` | Batch read from `_sessions` dictionary |
| `DemoConversationStore` (EF Core) | Single SQL query with correlated subquery for `LastMessage` (last turn's `UserMessage` or `AgentResponse`), filtered to sessions with at least one turn |

### Demo: session browser uses bulk API

`DemoSessionBrowserService` now calls `GetSessionSummariesAsync()` instead of looping through session IDs. Takes top 20 summaries *before* the per-session usage enrichment loop — eliminates ~160 wasted DB queries.

### Supporting changes

- **`AgentConversationScope.Separator`**: changed from `private const` to `public const` — needed by consumer code to parse agent-prefixed session keys.
- **`ConversationHistory.Title`**: new `init`-only property (nullable, defaults to `null`). Existing JSON deserializes cleanly.
- **`ConversationSessionEntity.Title`**: new nullable column for EF Core stores.

## Tests

- **7 new tests** in `ConversationStoreTests.cs`: metadata projection, `::agent::` parsing, `maxCount` limiting, ordering by last activity, title fallback to first user message.
- Core.Tests, Components.Tests, IntegrationTests, Cli.IntegrationTests: all pass.
- **4 pre-existing failures** in `AgentBlazor.Cli.Analysis.Tests` (`ExistingAppScaffoldPlannerTests` — template string assertion mismatches). Verified pre-existing: they fail identically on the previous commit and are unrelated to this release's changes.

## Upgrade notes

- **No breaking changes.** `GetSessionSummariesAsync` has a default interface method that falls back to `GetActiveSessionsAsync()` + `GetHistoryAsync()`. Existing custom stores continue to compile and work without modification.
- `AgentConversationScope.Separator` visibility changed from `private` to `public` — no consumer code should be affected.
- `ConversationHistory.Title` and `ConversationSessionEntity.Title` are nullable additions with `null` defaults — existing data deserializes cleanly.
