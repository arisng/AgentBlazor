# AgentBlazor 0.2.24-internal.1

> **Private/internal fork build.** This version is published only to the private local feed (`AGENTBLAZOR_LOCAL_FEED`, default `%USERPROFILE%\.agentblazor-feed`) and is **not** intended for public consumption. The `-internal.1` suffix is an unmistakable private marker so a future public `0.2.24` cannot collide after merging upstream `master`.

`0.2.24` makes chat markdown rendering beautiful and safe: a Markdig →
allowlist-sanitizer pipeline, client-side mermaid/nomnoml diagrams and syntax
highlighting, copy buttons on code blocks, and a configurable
`MarkdownOptions` surface.

## Highlights

- **Sanitized markdown pipeline** — assistant/proactive timeline messages are
  rendered via Markdig (`UseAdvancedExtensions().DisableHtml()`) through a
  new allowlist sanitizer. Raw model-authored HTML is escaped (never
  executed); `iframe`, `style`/`id`/event attributes, and `data:` /
  `javascript:` URLs are stripped. Opt out with `MarkdownOptions.Sanitize =
  false` (raw HTML is still escaped by `DisableHtml()`).
- **Mermaid + nomnoml diagrams** — diagram fences render to SVG client-side
  on final messages (never mid-stream). Lazy UMD script loading (mermaid@11
  via jsdelivr, nomnoml 1.7.0 via cdnjs — nomnoml needs its `graphre`
  dependency loaded first, so both load as a chain). Rendered SVGs get
  `role="img"` + `aria-label`; broken diagrams degrade to their raw source.
- **Syntax highlighting** — fenced code blocks are highlighted with
  highlight.js 11.11.1 (cdnjs UMD). Markdig emits diagrams as
  `<pre class="mermaid">`, so the copy-button pass explicitly skips diagram
  containers — a button there appended "Copy" to the diagram source and
  broke mermaid parsing (caught by the new demo e2e).
- **Copy buttons** — code blocks get a hover-revealed Copy button
  (`navigator.clipboard` with `execCommand` fallback), flashing "Copied!".
- **`MarkdownOptions`** — `EnableMermaid`, `EnableSyntaxHighlighting`,
  `EnableCodeCopy`, `Sanitize`, plus `MermaidScriptUrl` /
  `NomnomlScriptUrl` / `HighlightScriptUrl` overrides (self-hosted
  fallback). Threaded through `AgentChatSurface` / `AgentChatWidget` /
  `AgentChatPanel`.
- **Idempotency** — a content-hash guard (source hash passed from the
  component, stashed diagram sources + copy-button exclusion for the
  direct-JS fallback) means Blazor re-diffs and hydration never double-render
  diagrams or duplicate buttons.

## Behavior changes

- Timeline markdown is now sanitized (previously raw LLM HTML flowed into
  `MarkupString`). If you were relying on custom HTML attributes in agent
  output, they are stripped unless `MarkdownOptions.Sanitize = false`.
- Mermaid diagram theme follows the chat surface `data-theme` (dark → mermaid
  `dark`).
