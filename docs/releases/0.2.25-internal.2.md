# AgentBlazor 0.2.25-internal.2

> **Private/internal fork build.** This version is published only to the private local feed (`AGENTBLAZOR_LOCAL_FEED`, default `%USERPROFILE%\.agentblazor-feed`) and is **not** intended for public consumption.

## New: Per-turn token usage & cost persistence

Every turn that reaches the model now carries its raw provider token usage through the
library, and the Demo persists it (tokens **and** estimated cost) in the conversation
database — surfaced per-session in the session browser.

### Library — `ConversationTurn.Usage`

- **`ConversationTurnUsage`** — a slim, immutable value type (`InputTokens` /
  `OutputTokens` / `TotalTokens` / `CachedInputTokens`) projected from
  `AgentTurnResponse.Usage` via `ConversationTurnUsage.FromUsageDetails`.
- **`ConversationTurn.Usage`** — populated at **both** turn-creation sites
  (`RuntimePersistenceRecords.CreateConversationTurn` and
  `AgentChatSurface.CreateConversationTurn`), so every store backend can persist it.
  Null for turns that never reached the model (short-circuits, no-agent, approval
  continuations) — an unpriced turn is not the same as a free one.
- **`AgentChatSurface.AreEquivalentTurns`** now compares `Usage`, so enriched/edited
  turns re-patch usage through `UpdateTurnAsync` instead of being skipped as "equivalent".
- **Additive only** — no breaking changes to `IConversationStore`, `AgentTurnRequest`, or
  existing turn payloads.

### Demo — pricing, persistence, surfacing

- **`DemoTokenPricing` config section** (new, separate from `DemoLogging`):
  `InputTokenCostPerMillion` 0.15, `OutputTokenCostPerMillion` 0.60,
  `CachedInputTokenCostPerMillion` 0.0075 (gpt-4o-mini rates).
- **`DemoUsageCostCalculator`** — single shared pricing source: the JSONL request log and
  the conversation DB can never disagree about what a turn cost. Cached input tokens are
  billed at the discounted cached rate (clamped to `cached ≤ input`).
- **`demo_conversation_turns` columns** — `PromptTokens`, `CompletionTokens`,
  `TotalTokens`, `CachedInputTokens`, `EstimatedCost` (REAL via `HasConversion<double>`
  so SQLite can SUM it), `EstimatedCostCurrency`, and a rate snapshot
  (`InputTokenCostPerMillion` / `OutputTokenCostPerMillion` /
  `CachedInputTokenCostPerMillion`) so historical rows stay auditable after a rate change.
- **Idempotent schema upgrade** — `DemoConversationDatabaseInitializer` adds missing
  columns at startup (`PRAGMA table_info` + `ALTER TABLE ADD COLUMN`, duplicate-column
  race guard). No EF migrations; pre-existing `.db` files keep working.
- **Session browser** — per-session breakdown chips (`Prompt 2M · Completion 500K ·
  Cached 800K · Cache hit 40% · Total 2.5M · $0.00045 USD`), compact `in / out` list chip
  with full hover breakdown, and K/M/B token formatting. Fed by
  `IDemoConversationUsageQuery` (Null implementation when the store is not EF Core).
- JSONL request-log format is unchanged; the daily cost cap now reflects discounted
  cached pricing.
