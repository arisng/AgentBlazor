# AgentBlazor 0.2.24-internal.3

> **Private/internal critical-fix build.** This version is published only to the private local feed (`AGENTBLAZOR_LOCAL_FEED`, default `%USERPROFILE%\.agentblazor-feed`) and is **not** intended for public consumption.

## Critical fix: incremental conversation persistence

`AgentChatSurface` previously rewrote the entire conversation history after every agent turn (`ClearSessionAsync` + re-`AppendTurnAsync` for every turn in the display list). That full-history rewrite had eight design flaws — redundant I/O, non-atomic clear + re-append, session-metadata destruction, context loss outside the execution scope, in-memory split-brain hazard, race conditions, O(N) cost per turn, and a scope-bridging workaround. This release eliminates the rewrite:

- **`ConversationTurn.TurnId`** — stable identity for targeted operations (persisted by every store, unique per `(SessionId, TurnId)`).
- **Three new `IConversationStore` operations** (implemented in `InMemoryConversationStore` and `JsonFileConversationStore`):
  - `UpdateTurnAsync(sessionId, turnId, turn)` — patch a single turn in place.
  - `DeleteTurnAsync(sessionId, turnId)` — remove a single turn.
  - `ReorderTurnsAsync(sessionId, orderedTurnIds)` — re-sequence turns without rebuilding the session.
- **`AgentChatSurface.PersistDisplayedTurnAsync`** now appends once (normal turns are already persisted by the runtime) and applies targeted patches for enriched/edited turns. The `RewriteConversationHistoryAsync` helper is deleted; `ClearSessionAsync` is no longer called by the persistence path.

## ⚠️ Breaking change

Custom `IConversationStore` implementations (demo, consumer EF/Redis/BFF stores) MUST add the three new methods and persist `ConversationTurn.TurnId`. The canonical EF reference is in `.github/skills/ab-conversation-store/references/ef-core-sqlserver.md`.

## New: Demo EF Core store option

The Demo gains a third store selection, `DemoConversation:Store=EFCore`, backed by EF Core + SQLite (`DemoConversationStore`, `DemoConversationDbContext` with a unique `(SessionId,TurnId)` index, `TurnSequence` ordering). Selection: `JsonFile` (default) | `InMemory` | `EFCore`.
